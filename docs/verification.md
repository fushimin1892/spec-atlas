# 最終検証記録

検証日: 2026-10-23（日本時間）。この記録は全情報の正しさ・最新性を保証するものではありません。

## 対象と結果

- CPU 231件、GPU 128件、AI 58件のID・数値・出典・表示用データ構造を検査。
- CPUは230型番の6技術項目、83型番の発売日を含む7項目、掲載済み230件のPassMarkスコアが保存資料と一致。4700Sの公称電力を確定できず、全231型番一致には至っていません。
- GPUは独立GPU123型番中122型番のVRAM・公称電力、11型番の発売日を含む3項目が保存資料と一致。RX 590の公称電力は参考資料との照合に留まります。内蔵GPU5型番は専用VRAM・GPU単体電力の数値対象外であり、一致件数へ足しません。メーカー製カードの照合にはカード固有の条件あり。掲載済み120件のスコアはUL公式の取得エラーにより未再照合、8件は空欄。
- 初回の5項目修正に加え、3500Xの発売日をAMD中国向け公式値へ修正、4700SのL3を8MBで補完・未確定の65Wを取り下げ、RX 560の電力を60〜80Wの範囲へ変更。詳細は[照合報告](hardware-audit.md)と[修正記録](hardware-corrections.json)を参照。
- AIは指定6系列45モデルを整備し、既存の指定外13モデルを保持。公式資料で確認できた項目、未確認、非公表、APIと重み版、通常コンテキストと条件付き拡張上限を区別。

## 自動検証

以下はすべて成功。保存済み資料との比較であり、全提供元への常時オンライン照合ではありません。

```powershell
node tools/validate-data.mjs
node tools/audit-hardware.mjs --report
```

`js/`・`data/`の全JSと`tools/`の全JS/MJSは`node --check`で構文検査。`git diff --check`も成功。

掲載値を意図的に変えた場合の不一致判定、根拠のない項目を確認済みにしないこと、スコアと技術仕様の確認を混同しないこと、型番・容量違いの識別、取得エラーページの拒否を検査。

追加検査では、範囲の下限・上限の誤り、範囲からの不適切な効率計算、対象外の0GBへの置換、独立GPUの対象外化、参考資料の一次資料への昇格を検出することを確認。
