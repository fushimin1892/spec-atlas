## 自動検証

以下はすべて成功。保存済み資料との比較であり、全提供元への常時オンライン照合ではありません。

```powershell
node tools/validate-data.mjs
node tools/audit-hardware.mjs --report
```

`js/`・`data/`の全JSと`tools/`の全JS/MJSは`node --check`で構文検査。`git diff --check`も成功。

掲載値を意図的に変えた場合の不一致判定、根拠のない項目を確認済みにしないこと、スコアと技術仕様の確認を混同しないこと、型番・容量違いの識別、取得エラーページの拒否を検査。
