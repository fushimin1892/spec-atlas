# 技術仕様の追加照合記録

確認日: 2026-10-23（日本時間）。前回未確認だったCPU 2型番とGPU 32型番を再調査しました。**全件がメーカー資料で一致した状態ではありません。**

CPUは230/231型番、独立GPUは122/123型番が全技術項目一致。内蔵GPU5型番は専用VRAM・単体電力の数値対象外として区別。残る未確定はAMD 4700SとRX 590の公称電力です。

## 採用条件

- Ryzen 5 3500X: AMD中国向け公式ページで6技術項目と発売日を確認。英語ページは仕様欄がない。
- AMD 4700S: PassMark個別ページで5技術項目を照合。L3をCPUパッケージ合計8MBで補完。公称電力の資料差を解消できず、65Wは取り下げて未確認とした。メーカーによる電力確認済みとしては扱わない。
- RX 560: AMD公称の60〜80Wをそのまま掲載。80Wの固定値へ置き換えず、範囲から効率を計算しない。
- RX 590: 225Wは発売時実機レビューと参考照合。現在のAMD公式資料に公称電力の記載がなく、MSI ARMOR 8G OC固有の220Wを他カードへ流用しない。
- 内蔵GPU: メモリ共有の構造とCPUごとの電力設定を確認。GPU名に固定した専用VRAM・単体TGP/TBPの数値は対象外。一致や0GB・0Wとしては集計しない。
- TITAN X Pascal: 第三者が保存した2017年のNVIDIA公式ページPDFを保存日付きで採用。容量p.1と電力p.3を画像確認。現行URLの別製品への転送は採用しない。
- MSI・PNY製カード: 容量・メモリ規格・公称電力の条件を特定。すべてのメーカー製カードの値として保証しない。

## 証拠・検証

追加29資料のURL・確認日・取得本文SHA-256は[additional-sources.json](additional-sources.json)、項目別の期待値はdata/hardware-evidence.jsに保持。PDFは抽出文と該当ページの画像を確認。404・証明書エラー・別製品への転送は取得成功と扱わない。

`node tools/validate-data.mjs`・`node tools/audit-hardware.mjs --report`で検証。範囲の両端、対象外の0GBへの誤置換、独立GPUの対象外化、参考資料の確認済みへの昇格を検出する。テスト成功は未確定2件の解決を意味しない。
